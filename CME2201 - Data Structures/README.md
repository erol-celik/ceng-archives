# CME2201 - Data Structures

Data structures course assignments (Java).

| Folder | Description |
|---|---|
| `HW1 - Archive Management (Hashing)` | Media archive lookup system using a hash table (`HashedDictionary`), driven by a movie dataset (`movies_dataset.csv`). Includes a written report. |
| `HW2 -  Evulation Tree` | "Tree of Life" species evolution browser built on a general (n-ary) tree with a pre-order iterator (`GeneralTree`, `PreOrderTreeIterator`), driven by `treeoflife_nodes.csv`/`treeoflife_links.csv`. Includes a written report. |
