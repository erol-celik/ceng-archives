# CME2210 - Object Oriented Programming

Object-oriented programming course project: a console-based library management system (plain Java, no framework).

| Item | Description |
|---|---|
| `LibrarySystem/` | Git submodule — role-based (Admin/Librarian/User) library management app with a console launcher (`Launcher.java`), service-layer interfaces (`IAdminService`, `ILibrarianService`, `IUserService`), JSON-backed data (`datasets/books.json`, `datasets/people.json`), and a notification builder. This was a group assignment; the submodule is a **fork of a groupmate's repository** (`thetuhi/LibrarySystem`), copied to this account and **pinned to the final submitted commit** for archive stability (the upstream repo has since diverged into unrelated later work). See the submodule's own README for details. |
| `Report.pdf` | Project report. |
