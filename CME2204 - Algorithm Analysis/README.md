# CME2204 - Algorithm Analysis

Algorithm analysis/complexity course assignments (Java).

| Folder | Description |
|---|---|

| `HW2 - DP City Tour` | Dynamic-programming route planner for touring city landmarks (`CityMap`, `RoutePlanner`), driven by landmark/visitor-load datasets. |
| `HW3 - Greedy Market Sim` | Greedy-algorithm market simulation (`HW3.java`), with an accompanying write-up. |
